# Student Management System

A beginner full-stack web application built using React, Node.js, Express.js, and SQLite.

## Technologies Used
- React.js – Frontend
- Node.js – Backend
- Express.js – REST API
- SQLite – Database

## Features
- Student registration
- View student records
- Store student details in SQLite

## Project Structure
- frontend/ – React application
- backend/ – Node.js API and SQLite database

## How to Run

### Backend
```bash
cd backend
npm install
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Local URLs
- Frontend: http://localhost:5173
- Backend: http://localhost:5000
- Students API: http://localhost:5000/students
